DIGONTO SUBLIMATION  -  print on sublimation transfer paper with any 4-ink (CMYK) Epson printer, e.g. ET-2862
=====================================================================================================
First test version. Works with the printer's normal Epson driver (Ubuntu, macOS, Windows).

What the program does: layout of several pictures and copies on the page, mirror (transfer paper), colour management with
your RGB ICC profile, ink fine-tuning (amount and curve for cyan / magenta / yellow), sharp resampling to the resolution
you choose (300 - 1200 dpi) and optional gentle sharpening. It then hands one page at the real size to the Epson driver.

How to print
  1. Install the Epson driver for your printer once (Settings > Printer / driver setup help).
  2. Add pictures, set page size, then press Print. The driver dialog opens.
  3. In the driver dialog: colour management / colour adjustment OFF (no ICC, "No colour adjustment"), best quality,
     the sublimation paper type, scale 100 % (no fit-to-page).
  Also possible: "Save print-ready PNG / PDF" and print that file from any program (same driver settings).

Quality tips
  * Best colours: an RGB ICC profile made for YOUR printer + sublimation ink + paper (Settings > Add profile). Without it
    only the ink fine-tuning is applied.
  * Print a small test first and compare it with your old software on the same picture; then adjust the curve per ink.
  * Use 600 dpi or higher for photos and 300 dpi for large flat designs.

Not included: direct head control (the L800 mode of Digonto DTFRIP) - 4-ink printers like the ET-2862 are printed via the driver.
Maintenance tab: weekly reminder (print the nozzle check / keep-alive page), opens the Epson head-cleaning screens.
Digonto DTFRIP and Digonto Sublimation can be installed together; each has its own settings.

COLOUR PROFILES
  Colour profiles are not included. Add the CMYK profile (.icc / .icm) of your own printer
  (from your printer or ink seller, or your RIP software) in Settings > Add profile, then choose it in the Print tab.
